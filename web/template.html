Text ceiling: 0.972 (mammoth-1) vs. best local 0.869 (vllm-d3-flash, −10.3 pp). Vision ceiling: 0.947 (span-02 / pplx-decider) vs. best local 0.895 (vllm-d3-flash / Clef-Flash, −5.2 pp). Local models incur zero token costs, complete data privacy, and predictable low-latency inference.

Evaluation Metrics

  • Accuracy — proportion of tasks where the argmax selected option matched the ground truth label. For binary predicates (noul), threshold is 0.5; for ordinal scores, rounded to the nearest level.
  • Brier Score — mean squared error across the full probability distribution vector.
  • Expected Calibration Error (ECE) — 10-bin weighted absolute gap between model confidence and empirical accuracy.
  • p(gold) — probability mass allocated to the true gold option (directly informs Brier and NLL).
  • Latency (p50) — end-to-end wall-clock latency in milliseconds. Cloud metrics include OpenRouter transport and provider queueing; local metrics measure dedicated GPU inference.
  • Cost — cumulative cost based on reported token usage.

Limitations & Boundary Conditions

  • Text Corpus: 107 tasks. A difference under ~10 percentage points is not statistically resolvable at n=107 (paired bootstrap CIs are reported).
  • Vision Corpus: 20 ladder tasks (4 per level). Each task represents 25% of its level score.
  • Local Hardware Limit: Tested strictly within an 8 GB VRAM budget on consumer hardware.
  • Ground truth labels are analytically authored with written rationales, not crowdsourced.
  • Third-party leaderboard scores (Jev Decision Index, S1MB) measure different splits and cannot be directly equated with argmax task accuracy.
