# Бенчмарк Decision-моделей (Decision Models Benchmark)

[English](README.md) | [Русский](README.ru.md)

Эмпирический воспроизводимый бенчмарк для **System One / Decision-моделей** в **облачных API** (OpenRouter, Respan) и в **локальном окружении** через `llama.cpp`.

В отличие от стандартных генеративных чат-моделей, decision-модели представляют собой специализированные движки маршрутизации и классификации. Их задача — выдавать калиброванное распределение вероятностей по конечному набору вариантов за один прямой проход (forward pass). Бенчмарк измеряет argmax-точность, калибровку вероятностей (Brier score, ECE), задержку инференса и стоимость на **107 текстовых задачах** и **20 визуальных задачах лестницы сложности (Vision Ladder)**.

---

## 🖥️ Спецификация тестового стенда (Hardware Testbed)

Все локальные модели тестировались непосредственно на потребительском ПК с жестким ограничением бюджета памяти **≤ 8 ГБ VRAM**:

| Компонент | Спецификация |
|---|---|
| **GPU** | **NVIDIA GeForce RTX 2060 SUPER** (8 192 МиБ GDDR6, драйвер 581.80, CUDA 12.4) |
| **CPU** | **Intel Core i5-14600KF** (14 ядер: 6P + 8E, 20 потоков, до 5.3 ГГц) |
| **RAM** | **48 ГБ** (системная оперативная память) |
| **ОС** | **Windows 10 x64** |
| **Локальный движок** | `llama.cpp` (сборка CUDA 12, `llama-server.exe` с флагом `-ngl 99` для полной выгрузки слоев в GPU) |
| **Лимит бюджета** | **Строго ≤ 8 ГБ VRAM** (квантование Q4_K_M / Q8_0; исключение свопа в системную RAM) |

> **Почему именно лимит 8 ГБ?**  
> Корпоративные тесты обычно проводятся на серверах с картами уровня A100/H100 (80 ГБ). Данный бенчмарк проверяет, способны ли компактные decision-модели обеспечить быстрое, конфиденциальное и бесплатное принятие решений на обычном настольном компьютере пользователя.

## 💡 Ключевые выводы

1. **Реальная применимость на ПК**: Модель `vllm-d3-flash` (2.8 ГБ VRAM) показала **86.9% точности на тексте** и **89.5% на зрении** на видеокарте RTX 2060 SUPER с задержкой **~58 мс**, опережая часть платных облачных сервисов при полной автономности и нулевой стоимости запроса.
2. **Эффективность визуала**: Локальная модель `Clef-Flash` занимает менее 2 ГБ VRAM, но делит второе место по зрению (**89.5%**) наравне с облачными тяжеловесами.
3. **Провал ультракомпактных моделей**: Модели менее 2 ГБ (`Julia-1` — 36.4%, `Laya` — 51.4%, `vllm-d3-edge` — 53.3%) непригодны для продакшена: они демонстрируют результаты на грани случайного угадывания при усложнении логики.
4. **Облачные эталоны**: `baseten/mammoth-1` остается лидером по тексту (97.2%), а `respan/span-02` и `perplexity/pplx-decider-v1.2` лидируют по мультимодальному зрению (94.7%).

## 🌐 Интерактивный веб-отчет

Все данные бенчмарка собраны в автономный одностраничный веб-отчет:
* **Без внешних запросов**: Работает локально без интернета, без CDN, внешних шрифтов и библиотек.
* **Встроенные данные**: Полный массив наблюдений, калибровочные кривые и срезы задержек встроены прямо в HTML-файл.
* **Сохранение фильтров**: Состояние фильтрации записывается в хеш URL для передачи ссылок.

```powershell
# Сборка автономного отчета
python -m src.web_report build

# Проверка контракта и целостности DOM (более 40 тестов)
node tests/web.test.js
```

Откройте `reports/index.html` (или `docs/index.html`) двойным кликом в браузере.

## 🚀 Воспроизведение и запуск

### Требования
* Python 3.10+
* Node.js (для прогона тестов)
* Ключ API OpenRouter (для тестирования облачных моделей)
* Сборка `llama.cpp` с поддержкой CUDA 12 (для локальных тестов на GPU NVIDIA)

### Запуск
```powershell
# 1. Клонирование репозитория
git clone https://github.com/Davidson235/decision-models-benchmark.git
cd decision-models-benchmark

# 2. Настройка окружения
Copy-Item .env.example .env
# Укажите свои ключи OPENROUTER_API_KEY / RESPAN_API_KEY в файле .env

# 3. Запуск самопроверки
python -m src.verify

# 4. Прогон тестов веб-интерфейса
node tests/web.test.js
```
